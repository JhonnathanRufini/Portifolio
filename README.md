# Portfólio — Jhonnathan Rufini Pereira

Portfólio profissional com estudos de caso sobre engenharia, transformação digital, automação de processos e soluções aplicadas à operação.

## Conteúdo

- Estudos de caso: ORION, SHECard, LAIA, Matriz PTW e Programa de Ideias.
- Galerias com imagens dos projetos.

## Executar localmente

Não há dependências externas. Com Node.js instalado, gere o manifesto de galerias e manuais:

```bash
npm run build
```

Depois, abra `index.html` em um navegador. O projeto também pode ser hospedado como site estático.
